# Individual key heights

Full keyboard named profiles now support per-key height percentages from 50% to 300%, alongside existing width overrides. Choose a key in the dashboard, adjust **Height**, and save the profile. Resetting the height removes only that key's height override.

The optional `keyHeights` map uses key labels as keys and integer percentages as values. Missing values render at 100% and older profiles remain compatible. Height controls do not affect the compact keyboard layout.

Keys remain in their keyboard rows; arbitrary per-key X/Y positioning is a separate follow-up.
