# Custom FPS layouts

Create a named profile, select **Custom / FPS**, and select the keys to keep visible. The initial preset shows 1–5, WASD, Shift, Ctrl, and Space. Unlike Compact, keys remain visible when released. You can use the visual keyboard editor for sizing and offsets, then save and copy the named profile's OBS URL.

The visible-key list is independent of hidden-input filtering. Layouts are profile-specific and are included in profile JSON exports.
