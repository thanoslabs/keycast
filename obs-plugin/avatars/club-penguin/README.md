# Club Penguin avatar export

This folder intentionally does not contain fabricated or unlicensed artwork or a fake .moc3.

## Required authoring inputs
- Previously approved Club Penguin BongoCat PNG/ZIP pack (612 × 354 alignment).
- Layer-separated body, head, beak, eyes, flippers, keyboard and mouse artwork.
- A Cubism Editor project with mesh deformation and matching parameters from
  docs/club-penguin-cubism-rig.md.
- Genuine Cubism Editor runtime export: model3.json, moc3, textures, optional motions.

Do not replace the default BongoCat profile. Keep this as a separate avatar.
The source art is not in this repository; supply it before claiming a completed rig.
Do not commit proprietary Cubism SDK files. Confirm artwork distribution rights.
